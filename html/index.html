Container 1 · 핵심 기능

주행부터 주차까지, 차량 보호에 꼭 필요한 기능만 담았습니다

사고는 늘 예고 없이 찾아옵니다. Premium Blackbox는 주행·주차·야간 상황을 모두 고려해, 꼭 필요한 장면만 또렷하게 남길 수 있도록 설계되었습니다.

4K UHD 초고화질로 번호판, 차선, 표지판까지 섬세하게 기록
야간/터널/역광 환경에서도 디테일을 살려주는 야간 최적화 알고리즘
충격 발생 시 자동으로 보호 영역에 저장되는 G-센서 충돌 감지
4K 초고화질 녹화
60fps 부드러운 프레임
3중 충돌 감지 단계
전방 4K 녹화 옵션: 후방 FHD 긴급 저장 버튼 주차 중 이벤트 촬영

평소에는 조용히, 필요할 때는 강력하게 작동하는 블랙박스답게 무의미한 영상은 최소화하고 중요한 순간만 안전하게 간직합니다.

Container 2 · 야간 / 주차 보안

내 차를 지키는 시간은, 시동이 꺼진 뒤부터입니다

퇴근 후 골목길, 아파트 지하주차장, 낯선 주차 구역에서도 Premium Blackbox는 차량 주변을 부드럽게 감시하고, 움직임과 충격을 자동으로 감지해 기록합니다.

움직임 감지 기반의 스마트 주차 모드로 불필요한 저장 최소화
저전압 차단 기능으로 배터리 방전을 방지하며 안심 사용
문콕, 긁힘, 접촉 사고 등 주차 중 발생하는 이벤트 자동 분류
주차 모드 자동 전환 움직임/충격 동시 감지 배터리 보호 이벤트 알림

나중에 확인해야 할 장면만 깔끔하게 모아 볼 수 있도록 주행/주차/이벤트 영상이 자동으로 폴더별 정리됩니다.

Container 3 · 모바일 & GPS

핸드폰에서 바로 확인하고, 지도 위에서 다시 돌아보세요

Wi-Fi 앱 연동으로 블랙박스를 분리하지 않고도 영상을 바로 확인하고 공유할 수 있습니다. GPS 기능과 함께라면, 사고 위치와 속도 정보까지 한눈에 확인할 수 있습니다.

전용 앱으로 실시간 라이브 뷰, 과거 영상 탐색, 파일 내보내기 지원
GPS 정보로 사고 구간, 이동 경로, 속도까지 동시에 기록
펌웨어 업데이트도 앱에서 간편하게 진행 가능
iOS / Android 지원 와이파이 연결 지도 기반 재생 펌웨어 OTA

사고가 났을 때, 영상과 위치·속도 정보가 함께 있다면 보험사나 경찰에도 더 명확하고 설득력 있게 상황을 설명할 수 있습니다.

Container 4 · 어떤 타입을 선택할까?

내 운전 패턴에 딱 맞는 블랙박스 타입을 골라보세요

하루 평균 주행 거리, 주차 환경, 예산에 따라 추천 타입이 달라집니다. 가장 중요한 건 “내 차가 자주 겪는 상황”을 정확히 아는 것에서부터 시작됩니다.

출퇴근 위주 · 비교적 한산한 도로 → 전방형 4K 모델 추천
골목길, 지하주차장, 뒷차 추돌 우려 → 전·후방 모델 추천
장거리/고속도로 주행이 잦은 운전자 → GPS + 고용량 메모리 구성 추천
전방 전용 전·후방 듀얼 상시전원 키트 고용량 메모리

다음 페이지에서 각 타입별 상세 스펙과 추천 사용 환경을 더 자세히 비교해 볼 수 있습니다.
